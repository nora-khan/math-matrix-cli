# Terminal Calculator 🔢🧮

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-green.svg)](https://www.python.org/)
[![CI](https://github.com/nora-khan/math-matrix-cli/actions/workflows/ci.yml/badge.svg)](https://github.com/nora-khan/math-matrix-cli/actions)

AST-safe, zero-eval scientific and financial calculator for terminal workflows.

## Highlights
- 🛡️ **Zero Vulnerability**: Evaluates mathematical syntax trees via Python's AST rather than hazardous `eval()`.
- 📐 **Scientific Helpers**: Native support for trigonometry, square roots, exponents, and logs.
- 💵 **Compound Interest**: Built-in annualized compounding calculation module.

## Quickstart
```bash
python calculator.py "2**10 + sqrt(144)"
# > 2**10 + sqrt(144) = 1036.0
```
